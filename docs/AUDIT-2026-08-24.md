# Audit proyek — 24 Agustus 2026

## Ringkasan

Audit mencakup struktur repository, backend Go, schema/migrasi PostgreSQL, kontrak SSO dan Laci, frontend Next.js, dependency, type safety, aksesibilitas dasar, responsive layout, serta konsistensi dokumentasi.

## Temuan yang diperbaiki

- Menghapus implementasi backend Node/Prisma, binary build, patch/reject file, lockfile ganda, route duplikat, dan komponen UI tanpa pemakai.
- Mengganti migrasi Prisma dengan migrator Go ber-checksum yang tetap mengenali riwayat Prisma lama.
- Menambahkan kolom riwayat pendidikan/pengkaderan yang sebelumnya dipakai kode tetapi tidak dibuat migrasi.
- Memperbaiki validasi config, session TTL, secure cookie production, timeout HTTP/server, graceful shutdown, error JSON, dan pembatasan body.
- Membuat OAuth state benar-benar sekali pakai secara atomik dan memakai endpoint hasil OIDC discovery.
- Memverifikasi HMAC webhook, bentuk payload, status, replay protection, transaksi, dan audit log.
- Menghentikan kebocoran error database serta logging payload pribadi.
- Menambahkan validasi backend, optimistic locking, perlindungan edit saat pending, idempotency submit, dan pemeriksaan error transaksi.
- Mencegah edit profil menghapus field terenkripsi lama dan mencegah status menjadi pending sebelum Laci menerima data.
- Menghapus penyimpanan NIK/alamat dari `localStorage`.
- Menghapus `any`, import mati, duplikasi shell, script lint yang rusak, dependency dan komponen tak terpakai.
- Mendesain ulang total landing, shell anggota, profil, form bertahap, loading, dan error dengan bahasa visual modern yang konsisten serta primitive shadcn/Base UI.
- Memperbaiki overflow mobile, hierarki konten, label aksesibel, nama tampilan Select (bukan ID internal), focus state, empty state, disabled state, dan navigasi antar-langkah.
- Memindahkan pengambilan organisasi awal ke React Server Components dan menjalankannya paralel dengan sesi/profil agar halaman tidak menunggu fetch ulang setelah hidrasi.
- Menambahkan font lokal ter-bundle, token tema terpusat, reduced-motion handling, dan pembatasan serialisasi client dengan menjadikan tampilan profil sebagai Server Component.
- Merapikan ulang form menjadi progress horizontal tanpa sidebar memanjang, memisahkan identitas SSO dari field editable, dan mengganti tanggal native dengan Calendar + Popover shadcn.
- Menyeragamkan Input, Select, Textarea, dan Date Picker pada satu border solid `1px` tanpa shadow atau focus ring bertumpuk.

## Verifikasi

- Backend: `go test -race ./...`, `go vet ./...`, dan pemeriksaan `gofmt`.
- Frontend: TypeScript strict + unused checks, ESLint tanpa warning, dan Next.js production build.
- `npm audit`: tidak menemukan vulnerability pada dependency yang terpasang saat audit.
- Enam migrasi dijalankan dua kali pada database PostgreSQL sementara untuk memverifikasi schema bersih dan idempotensi migrator; database sementara kemudian dihapus.
- Visual QA dilakukan pada landing desktop/mobile, form profil, dan profil terverifikasi. Viewport mobile 390 px tidak memiliki horizontal overflow.

## Risiko yang masih memerlukan sistem eksternal

- Uji integrasi nyata membutuhkan PostgreSQL berisi migrasi, tenant SSO uji, dan sandbox Laci.
- Rate limiting sebaiknya diterapkan pada reverse proxy/API gateway agar konsisten lintas replika.
- Timestamp webhook dan toleransi replay waktu harus disepakati lebih dulu dengan Laci.
- Rotasi encryption key memerlukan desain key versioning dan migrasi ciphertext.
- E2E login–submit–webhook belum dapat diautomasi tanpa credential dan fixture sandbox.
